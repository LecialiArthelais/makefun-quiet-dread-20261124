One code review comment, 75 characters, that approves a pull request while carrying quiet existential dread. The reviewer signs off knowing a bug bearing their name is somewhere in the diff — and it is patient.

> Approved. Somewhere in here is a bug with my name on it, and it is patient.

## Run it

```sh
python3 main.py
```

Writes the comment to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./entry.txt` when the variable is unset). Stdlib only, no network.
